# JavaScript Playground

Laboratório didático progressivo para introdução ao JavaScript.

## Estrutura

```text
javascript-playground/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Módulos planejados

1. Introdução ao JavaScript
2. Eventos
3. Seleção de elementos do DOM
4. Alteração de conteúdo
5. Alteração de estilos
6. Variáveis e valores
7. Entradas de dados
8. Decisões
9. Funções
10. DOM dinâmico
11. Animações e interações
12. JavaScript assíncrono

## Estratégia didática

Cada módulo seguirá uma estrutura semelhante:

- conceito;
- demonstração;
- código;
- desafio.

A implementação dos conteúdos será feita progressivamente com a turma.
