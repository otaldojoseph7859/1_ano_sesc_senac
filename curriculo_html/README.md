# 📄 Currículo HTML — Introdução Prática ao HTML

Projeto educacional desenvolvido para introduzir alunos aos fundamentos do **HTML** por meio da construção de seu primeiro documento de forma prática e progressivamente autônoma.

A atividade utiliza a estrutura de um currículo como contexto para apresentar diferentes tags HTML, trabalhar a organização hierárquica das informações e estimular os alunos a investigar como transformar conteúdo em uma página interpretada pelo navegador.

---

## 🎯 Sobre o projeto

O `curriculo_html` foi desenvolvido como uma das primeiras atividades práticas de HTML para alunos iniciantes em **Desenvolvimento Web**.

Neste momento da aprendizagem, o objetivo não é criar uma página visualmente sofisticada nem trabalhar estilização com CSS.

O foco está em uma pergunta muito mais fundamental:

**Como podemos utilizar HTML para estruturar e atribuir significado às informações de uma página?**

Para trabalhar esse conceito, escolhi a construção de um currículo porque sua estrutura é simples, familiar e composta por diferentes tipos de informação:

* nome;
* informações de contato;
* objetivo profissional;
* apresentação pessoal;
* habilidades;
* conhecimentos técnicos;
* experiências;
* formação;
* cursos;
* idiomas;
* interesses;
* referências.

Essa variedade permite apresentar diversas tags HTML dentro de um contexto compreensível para alunos que estão tendo seus primeiros contatos com desenvolvimento web.

---

# 💡 Por que este projeto foi criado?

Um dos desafios ao ensinar programação para iniciantes é evitar que o primeiro contato com código seja baseado apenas em teoria e memorização de sintaxe.

Por esse motivo, esta atividade não foi planejada para que os alunos simplesmente copiem um código apresentado pelo professor.

A proposta é apresentar um **resultado visível no navegador** e transformar esse resultado em um problema a ser investigado.

O aluno observa elementos como:

* títulos com diferentes tamanhos;
* parágrafos;
* linhas horizontais;
* listas;
* links;
* textos destacados;
* abreviações;
* citações;
* informações organizadas hierarquicamente.

A partir disso, precisa descobrir quais elementos HTML podem ser utilizados para reproduzir aquela estrutura.

O código deixa de ser o ponto de partida.

**O problema passa a ser o ponto de partida.**

---

# 🧠 Como cheguei a esta abordagem?

A atividade foi construída a partir de uma progressão simples:

**observar → investigar → experimentar → errar → corrigir → compreender**

Em vez de apresentar todas as tags e posteriormente solicitar uma atividade, primeiro é apresentado aquilo que deverá ser construído.

Isso cria uma necessidade concreta para o conhecimento.

Quando o aluno percebe que precisa criar um título, surge a necessidade de descobrir como os títulos funcionam.

Quando precisa criar uma lista, surge a necessidade de conhecer `<ul>`, `<ol>` e `<li>`.

Quando precisa criar um link, surge a necessidade de compreender `<a>` e seus atributos.

Dessa forma, cada novo elemento HTML aparece como resposta a um problema encontrado durante o desenvolvimento.

O objetivo é fazer com que o aluno não memorize apenas:

```html
<h1>Meu título</h1>
```

mas compreenda:

> "Preciso representar o título principal da minha página. Qual elemento HTML possui esse significado?"

Essa mudança é importante para desenvolver raciocínio e autonomia desde as primeiras aulas.

# 🎓 Objetivos de aprendizagem

Ao concluir a atividade, espera-se que o aluno seja capaz de:

* compreender a estrutura básica de um documento HTML;
* criar um arquivo `.html` de forma autônoma;
* abrir e visualizar uma página HTML no navegador;
* identificar a função do `<head>` e do `<body>`;
* criar títulos e subtítulos respeitando uma hierarquia;
* escrever e organizar parágrafos;
* utilizar diferentes tipos de listas;
* criar links;
* realizar quebras de linha;
* destacar informações importantes;
* utilizar elementos semânticos básicos para textos;
* interpretar código HTML existente;
* pesquisar tags desconhecidas;
* identificar erros simples de estrutura e sintaxe;
* transformar uma referência visual em código;
* desenvolver maior autonomia na resolução de problemas.

# 🧩 Metodologias utilizadas

## Aprendizagem Baseada em Problemas

A atividade parte de um problema:

> **Como reproduzir utilizando HTML o currículo apresentado no navegador?**

Os alunos precisam analisar o resultado, identificar os elementos necessários e construir uma possível solução.

O professor atua como orientador durante o processo, oferecendo direcionamento quando necessário sem entregar imediatamente a resposta completa.

---

## Aprendizagem pela prática

Os conceitos são apresentados enquanto existe uma necessidade concreta de utilizá-los.

O aluno aprende HTML **escrevendo HTML**.

A teoria é utilizada para explicar e consolidar aquilo que está sendo experimentado durante o desenvolvimento.

---

## Investigação e descoberta

Nem todas as respostas precisam ser fornecidas antecipadamente.

Algumas tags podem ser apresentadas como desafios para que os alunos pesquisem:

* o que a tag faz;
* como sua sintaxe funciona;
* onde poderia ser utilizada;
* qual significado ela atribui ao conteúdo.

Isso estimula uma habilidade fundamental para qualquer profissional de tecnologia: **aprender a buscar informações técnicas de forma autônoma**.

---

## Decomposição de problemas

O currículo completo pode parecer complexo para um aluno iniciante.

Por isso, o problema é dividido em partes menores:

1. criar a estrutura HTML;
2. adicionar o nome;
3. adicionar informações de contato;
4. criar o objetivo;
5. adicionar habilidades;
6. organizar conhecimentos;
7. adicionar experiências;
8. adicionar formação;
9. criar links e elementos adicionais.

Em vez de resolver todo o projeto de uma vez, o aluno aprende a solucionar **um pequeno problema por vez**.

---

## Aprendizagem através do erro

Erros de sintaxe e estrutura fazem parte da atividade.

Tags não fechadas, elementos posicionados incorretamente e resultados diferentes do esperado são utilizados como oportunidades para desenvolver:

* leitura de código;
* atenção aos detalhes;
* interpretação;
* depuração;
* raciocínio lógico.

O objetivo não é evitar erros, mas aprender a identificá-los e corrigi-los.

# 🔄 Fluxo da atividade

A atividade pode ser conduzida seguindo esta sequência:

### 1. Apresentação

O professor apresenta o currículo funcionando no navegador sem mostrar inicialmente todo o código responsável pelo resultado.

### 2. Observação

Os alunos analisam visualmente a página e identificam os diferentes tipos de conteúdo existentes.

### 3. Desenvolvimento autônomo

Cada aluno cria seu próprio arquivo HTML e tenta reproduzir a estrutura apresentada.

### 4. Investigação

### 5. Orientação

O professor acompanha individualmente os alunos, fazendo perguntas e oferecendo pistas antes de apresentar diretamente a solução.

### 6. Comparação

As diferentes soluções encontradas podem ser discutidas com a turma.

### 7. Correção

O arquivo `correcao.html` é utilizado para apresentar uma possível implementação completa.

### 8. Consolidação

As principais tags são revisadas e discutidas, relacionando sua sintaxe ao significado que possuem dentro do documento.

# 🏗️ Estrutura básica de um documento HTML

Todo documento utilizado no projeto parte de uma estrutura semelhante:

```html
<!DOCTYPE html>
<html lang="pt-br">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Currículo</title>
</head>

<body>

</body>

</html>
```

A seguir estão os principais elementos utilizados e o papel de cada um.

---

# 🏷️ Tags e elementos utilizados

## `<!DOCTYPE html>`

```html
<!DOCTYPE html>
```

Informa ao navegador que o documento utiliza **HTML5**.

Apesar de possuir uma sintaxe semelhante, `<!DOCTYPE html>` não é uma tag HTML convencional. Ele funciona como uma declaração que ajuda o navegador a interpretar o documento utilizando os padrões modernos do HTML.

---

## `<html>`

```html
<html lang="pt-br">
</html>
```

Representa o elemento raiz do documento HTML.

Praticamente todo o conteúdo da página fica dentro dele.

O atributo:

```html
lang="pt-br"
```

informa que o idioma principal do documento é português do Brasil.

Essa informação também contribui para recursos de acessibilidade e para a correta interpretação do conteúdo por diferentes ferramentas.

---

## `<head>`

```html
<head>
</head>
```

Contém informações sobre o documento que normalmente não aparecem diretamente como conteúdo da página.

Dentro dele podem existir informações como:

* título;
* codificação de caracteres;
* configurações de responsividade;
* referências a outros arquivos.

---

## `<meta>`

Exemplo:

```html
<meta charset="UTF-8">
```

A tag `<meta>` fornece metadados sobre o documento.

Neste caso, `charset="UTF-8"` define a codificação de caracteres, permitindo a correta interpretação de acentos, cedilhas e diversos outros caracteres.

Outro exemplo utilizado:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Essa configuração ajuda o navegador a ajustar corretamente a largura da página em diferentes tamanhos de tela.

---

## `<title>`

```html
<title>Currículo - Chrystopher Ferreira</title>
```

Define o título do documento.

Normalmente ele aparece na aba do navegador e não diretamente no conteúdo visível da página.

---

## `<body>`

```html
<body>
</body>
```

Contém o conteúdo visível da página.

Títulos, textos, listas, links e demais informações apresentadas no navegador são inseridos dentro do `<body>`.

---

# 🔤 Títulos — `<h1>` até `<h4>`

Exemplos:

```html
<h1>Chrystopher Ferreira</h1>

<h2>Formação Acadêmica</h2>

<h3>Ensino Médio Técnico</h3>

<h4>Principais áreas estudadas</h4>
```

As tags `<h1>` até `<h6>` representam diferentes níveis de títulos.

Neste projeto utilizamos principalmente `<h1>`, `<h2>`, `<h3>` e `<h4>`.

A diferença entre elas não deve ser entendida apenas pelo tamanho visual.

Elas representam uma **hierarquia de conteúdo**.

De maneira simplificada:

* `<h1>` — título principal;
* `<h2>` — grandes tópicos;
* `<h3>` — subtópicos;
* `<h4>` — tópicos dentro dos subtópicos.

Essa hierarquia ajuda a organizar logicamente as informações.

---

# 📝 `<p>` — Parágrafo

```html
<p>
    Sou estudante e tenho grande interesse por tecnologia.
</p>
```

A tag `<p>` representa um parágrafo.

Ela deve ser utilizada para agrupar trechos de texto que formam uma ideia ou conteúdo textual relacionado.

---

# ↩️ `<br>` — Quebra de linha

```html
Curitiba - Paraná <br>
Telefone: (41) 99999-9999 <br>
E-mail: exemplo@email.com
```

A tag `<br>` realiza uma quebra de linha dentro do conteúdo.

Ela é útil quando existe uma necessidade real de separar informações em linhas diferentes sem criar novos parágrafos.

---

# ➖ `<hr>` — Separação temática

```html
<hr>
```

Representa uma mudança ou separação temática entre conteúdos.

Visualmente, os navegadores normalmente exibem uma linha horizontal, mas seu significado não deve ser entendido apenas como uma ferramenta para "desenhar uma linha".

Neste projeto, ela auxilia a separar visualmente os diferentes assuntos do currículo.

---

# 🔗 `<a>` — Link

```html
<a href="https://github.com/" target="_blank">
    Meu GitHub
</a>
```

A tag `<a>` cria um hiperlink.

O atributo `href` informa o endereço de destino.

```html
href="https://github.com/"
```

O atributo:

```html
target="_blank"
```

faz com que o endereço seja aberto em outra aba ou contexto de navegação.

Também podemos criar links para e-mail:

```html
<a href="mailto:chrystopher@email.com">
    chrystopher@email.com
</a>
```

---

# 💪 `<strong>` — Forte importância

```html
<strong>Tecnologia da Informação</strong>
```

A tag `<strong>` indica que determinado conteúdo possui forte importância.

Os navegadores normalmente exibem esse conteúdo em negrito, mas o significado da tag é mais importante que sua aparência visual.

---

# ✨ `<em>` — Ênfase

```html
<em>2026</em>
```

A tag `<em>` representa ênfase em determinado trecho.

Normalmente os navegadores apresentam seu conteúdo em itálico.

Assim como `<strong>`, sua finalidade não é simplesmente alterar a aparência do texto, mas atribuir significado.

---

# 🖍️ `<mark>` — Destaque

```html
<mark>desenvolvedor web</mark>
```

A tag `<mark>` representa um trecho destacado ou marcado por possuir relevância dentro de determinado contexto.

Os navegadores normalmente apresentam esse conteúdo com um fundo destacado.

---

# 🔡 `<abbr>` — Abreviação

```html
<abbr title="HyperText Markup Language">HTML</abbr>
```

Representa uma abreviação ou sigla.

O atributo `title` pode fornecer o significado completo da abreviação.

Neste exemplo:

* texto apresentado: `HTML`;
* significado informado: `HyperText Markup Language`.

---

# 💻 `<code>` — Código

```html
<code>git commit</code>
```

A tag `<code>` representa pequenos trechos de código, comandos ou elementos relacionados à programação.

Neste projeto ela permite demonstrar que diferentes tipos de conteúdo também possuem significados diferentes dentro do HTML.

---

# 📋 `<ul>` — Lista não ordenada

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

`<ul>` significa **unordered list**, ou lista não ordenada.

É utilizada quando a ordem dos itens não representa necessariamente uma sequência ou prioridade.

---

# 🔢 `<ol>` — Lista ordenada

```html
<ol>
    <li>Desenvolvimento Web</li>
    <li>Lógica de Programação</li>
    <li>Banco de Dados</li>
</ol>
```

`<ol>` significa **ordered list**, ou lista ordenada.

É utilizada quando existe sentido em apresentar os elementos seguindo uma determinada ordem.

---

# 🔹 `<li>` — Item de lista

```html
<li>HTML básico</li>
```

Representa um item pertencente a uma lista.

É utilizado dentro de estruturas como `<ul>` e `<ol>`.

---

# 📖 `<dl>` — Lista de descrição

```html
<dl>
</dl>
```

Representa uma lista formada por termos e suas respectivas descrições.

Neste projeto ela é utilizada para organizar habilidades e explicar cada uma delas.

---

# 🏷️ `<dt>` — Termo da descrição

```html
<dt>
    <strong>Resolução de problemas</strong>
</dt>
```

Define o termo ou nome que será descrito dentro de uma lista `<dl>`.

---

# 📄 `<dd>` — Descrição

```html
<dd>
    Procuro analisar cada desafio e encontrar diferentes alternativas.
</dd>
```

Representa a descrição relacionada ao termo definido anteriormente com `<dt>`.

---

# 💬 `<blockquote>` — Citação em bloco

```html
<blockquote>
    "Sempre podemos aprender algo novo quando estamos dispostos a tentar."
</blockquote>
```

Representa uma citação apresentada como um bloco separado do restante do conteúdo.

É adequada para citações mais extensas ou que mereçam destaque próprio.

---

# 🗨️ `<q>` — Citação curta

```html
<q>aprender fazendo</q>
```

Representa uma pequena citação inserida dentro do fluxo de um texto.

Ela permite também comparar duas formas diferentes de representar citações: `<q>` para conteúdos curtos e `<blockquote>` para citações em bloco.

---

# 🔼 `<sup>` — Texto sobrescrito

```html
B<sup>2</sup>
```

A tag `<sup>` apresenta determinado conteúdo como sobrescrito.

Pode ser utilizada, por exemplo, em:

* expoentes;
* referências;
* determinadas nomenclaturas.

No projeto, ela é apresentada como oportunidade de conhecer formas diferentes de representar informações textuais.

---

# 🔎 `<small>` — Informação complementar

```html
<small>
    Currículo desenvolvido como atividade prática de HTML.
</small>
```

Representa comentários laterais ou informações complementares, como observações e avisos.

Os navegadores normalmente apresentam seu conteúdo em tamanho menor.

# 🎯 Níveis de desafio

Para permitir que alunos com diferentes ritmos continuem evoluindo durante a mesma atividade, o projeto pode ser dividido em níveis.

## Nível 1 — Fundamentos

O aluno deverá conseguir utilizar:

* títulos;
* parágrafos;
* listas;
* linhas horizontais;
* estrutura básica do HTML.

## Nível 2 — Intermediário

O aluno deverá adicionar:

* links;
* quebras de linha;
* abreviações;
* destaques;
* listas de descrição.

## Nível 3 — Investigação

O aluno deverá pesquisar e encontrar uma aplicação coerente para elementos como:

* `<blockquote>`;
* `<q>`;
* `<code>`;
* `<sup>`;
* `<small>`.

A intenção não é apenas verificar se o aluno consegue utilizar uma tag.

A pergunta principal passa a ser:

> **Ele consegue compreender o significado da tag e decidir quando sua utilização faz sentido?**

---

# 🚫 O que propositalmente não é abordado

Neste projeto, não são introduzidos elementos estruturais mais avançados como:

```html
<div>
<section>
<article>
<table>
```

Essa decisão é intencional.

O projeto faz parte de uma sequência progressiva de aprendizagem. Seu objetivo é consolidar primeiro:

* estrutura básica do documento;
* hierarquia;
* conteúdo textual;
* listas;
* links;
* semântica textual básica.

Novos conceitos são introduzidos posteriormente conforme os alunos desenvolvem uma base mais sólida.

Da mesma forma, o projeto não possui como foco principal a estilização com CSS.

A intenção é evitar que decisões visuais desviem a atenção do conceito fundamental desta atividade:

**HTML é responsável por estruturar e atribuir significado ao conteúdo.**

# 👨‍🏫 Papel do professor
